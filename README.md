# Nurin'sLibrar – Library Management System

## 1. Project Description

Nurin'sLibrar is a Library Management System developed as an individual project for IMS566 – Advanced Web Design Development and Content Management.

This website is designed to help manage library activities, including book collections, registered members, borrowing records and book categories.

The system provides a simple, user-friendly and responsive interface to make library management more organised and convenient.

## 2. Features Included

The system includes the following features:

- **Login Page** – Allows users to access the library management system.
- **Register Page** – Allows users to register a library account.
- **Dashboard** – Displays library statistics, book categories and recently added books.
- **Books Management** – Allows users to view, search, add, edit and delete book records.
- **Members Management** – Allows users to view, search, add, edit and delete member records.
- **Borrowing Page** – Provides an interface for managing book borrowing activities.
- **Categories Page** – Displays and organises books according to different categories.
- **Search and Filter** – Helps users find specific records easily.
- **Dark Mode** – Provides an alternative display theme.
- **Responsive Design** – Supports desktop and mobile screen sizes.

## 4. Frameworks and Libraries Used

The following technologies and libraries were used to develop this project:

- **HTML5** – Structures the website content.
- **CSS3** – Styles the website layout and appearance.
- **JavaScript** – Adds interactive functions and website features.
- **Bootstrap 5.3.3** – Provides responsive layout and UI components.
- **Chart.js** – Displays book statistics through charts.
- **Google Chrome** – Used for website development and testing.
